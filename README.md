# Taskly — To-Do List (9-апта)

**Тақырып:** Тапсырмалар тізімін басқаруға арналған веб-қосымша (To-Do List).

## Мақсат
Пайдаланушыға оқу, жұмыс және жеке тапсырмаларын бір жерде жоспарлауға, басымдықтарын анықтауға және орындалуын бақылауға арналған веб-интерфейс жасау.

## 9-аптаның нәтижесі
HTML, CSS және JavaScript арқылы **4 адаптивті статикалық бет** дайындалды:
- `index.html` — басты бет және мүмкіндіктер.
- `register.html` — тіркелу формасының макеті және браузерлік валидация.
- `login.html` — кіру формасының макеті және браузерлік валидация.
- `tasks.html` — тапсырмалар тізімінің интерактивті демонстрациялық беті.

## Іске қосу
`index.html` файлын браузерде ашыңыз. Басқа беттерге мәзір арқылы өтіңіз. Интернет қосылымы болмаса да жүйе шрифттің балама нұсқасымен жұмыс істейді.

## Демонстрациялық мүмкіндіктер
- Тапсырма қосу, өңдеу, жою, аяқталды деп белгілеу.
- Санат, басымдық, мерзім таңдау.
- Мәтін бойынша іздеу және күйіне қарай сүзгі.
- Орындау статистикасы.
- Деректерді **сол браузердегі** `localStorage` арқылы сақтау.
- Мобильді құрылғыларға бейімделген дизайн.

## Маңызды шектеу
Бұл **9-аптаның frontend прототипі**. Кіру/тіркелу формалары шынайы аккаунт құрмайды: деректер серверге жіберілмейді, құпиясөз сақталмайды, валидациядан соң тек демонстрациялық бет ашылады. `localStorage` — MySQL дерекқорын алмастырмайды. PHP, MySQL және серверлік аутентификация 10–11 апталарда енгізіледі. Нақты құпиясөз қолданбаңыз.

## Келесі қадамдар
- 10-апта: PHP беттері, `include`, `$_POST`/`$_GET`, серверлік валидация.
- 11-апта: MySQL және PDO, қауіпсіз тіркелу мен авторизация.
- 12-апта: MySQL негізіндегі CRUD.

## GitHub-та 3 коммиттің ұсынылған мазмұны
1. `Create responsive landing and navigation`
2. `Add registration and login form layouts`
3. `Build task dashboard with interactive demo`
